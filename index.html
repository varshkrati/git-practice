Git & GitHub Cheat Sheet

Beginner-friendly Git commands with their meaning and usage.

Command Kya karta hai? Kab use karna hai?
git --version Check karta hai Git installed hai ya nahi. Starting mein
git config --global user.name "Name" Git mein apna naam set karta hai. First-time setup
git config --global user.email "email" Git mein email set karta hai. First-time setup
git init Current folder ko Git repository banata hai. New project mein Git start karte waqt
git status Project ki current situation batata hai. Bahut frequently
git add index.html index.html ke changes ko staging area mein rakhta hai. Commit se pehle
git add . Current project ke saare changes staging mein rakhta hai. Multiple changes ke liye
git commit -m "message" Staged changes ka save-point/history banata hai. Changes ready hone ke baad
git log --oneline Purane commits/history dikhata hai. History dekhni ho
git remote -v Check karta hai local project kis GitHub repo se connected hai. Connection check karne ke liye
git remote add origin REPO_URL Local project ko GitHub repo se connect karta hai. Usually ek baar
git push Local commits ko GitHub par bhejta hai. Apne changes online bhejne ke liye
git pull GitHub se latest changes computer mein laata hai. Latest version lene ke liye
git branch Branches dikhata hai aur current branch batata hai. Branch check karne ke liye

🔥 Most Important Workflow

git status → git add . → git commit → git push

Meaning:

git status → Kya change hua?

git add . → Changes ko next commit ke liye select karo.

git commit → Changes ka save-point banao.

git push → Changes ko GitHub par bhejo.
